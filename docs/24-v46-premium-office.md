# V4.6 プレミアムAIオフィス

## 目的

代表者が承認した `Bloom-L_AI_Company_reference` の構図・情報密度・人物の向きを、既存の業務データ連動を壊さずホーム画面へ反映する。

## レイヤー構造

1. **情景レイヤー**: `office-reference.png`。床、壁、家具、人物のピクセルアートを表示する。
2. **操作レイヤー**: 9社員の透明ボタン。1021×763を基準とした相対座標で人物へ重ねる。
3. **状態レイヤー**: 名前、状態バッジ、選択枠、稼働点。`CompanyStateView` の実値だけを表示する。
4. **業務UIレイヤー**: 選択社員カード、承認導線、準備中部門の説明、右パネル、KPI。
5. **ライブ社員レイヤー**: 9名の全身SVGスプライトを背景から分離して重ね、実DB状態に応じて通路を歩き、目的の部屋へ移動する。

画像内の仮名・仮数値をDB値として扱わない。進捗率や存在しない経過時間を生成しない。

## 状態連動アニメーション

| DB表示状態 | 移動先と到着後の動き |
|---|---|
| idle | 自席から中央通路を通ってラウンジへ移動し、複数地点をゆっくり巡回 |
| researching / creating | 自席へ戻り、タイピングを表す短い動作 |
| qa | 品質管理室へ移動し、品質確認動作 |
| meeting | 中央の会議テーブルへ移動し、会話動作 |
| awaiting_approval | 社長室前へ移動し、確認待ちの小さな動作 |
| done_today | ラウンジへ移動し、完了後の控えめな呼吸 |
| error / stale | 自席へ戻り、エラーは短い横揺れ、状態不明は静止 |
| budget_paused | ラウンジへ移動後に静止し、彩度を落として停止中であることを示す |

動きは `CompanyStateView.employees[].display.state` から決定し、見た目だけで架空の作業状態を作らない。各社員は自席→中央通路→目的地の順に複数のwaypointを移動する。距離から歩行時間を決定し、左右の向き・足踏み・影の縮小を連動させる。9名の出発を650msずつずらし、同時に全員が歩く状態を避ける。状態変更時は進行中のタイマーを破棄して新しい目的地へ向かうため、移動は中断可能である。

## レスポンシブとアクセシビリティ

- 901px以上: 1021:763のオフィス全景と人物ホットスポット。
- 900px以下: 全景を縮小せず、顔・役職・現在の仕事・状態を持つ社員カードへ切り替える。
- 各人物は44px以上のクリック領域と日本語の `aria-label` を持つ。
- 色だけで状態を表さず、アイコンと状態名を併記する。
- `prefers-reduced-motion` と画面内の一覧表示切替を維持する。
- `prefers-reduced-motion: reduce` では巡回を行わず目的地へ即時配置し、歩行・人物・状態シグナル・モバイル顔画像のアニメーションを停止する。
- 詳細情報・停止/再開操作・承認経路・DBイベント導出はV4以前の実装を変更しない。

## 顔つき歩行キャラと吹き出し(会話)

- **歩行キャラ**: これまで歩行スプライトは汎用SVG(色相違いのみ)で誰か分からなかった。各社員の**実際の顔クロップ**を頭に、統一されたBloom-Lジャケットの小さな体を組み合わせた「ポケモンの2Dオーバーワールド」風キャラにし、9名+マネージャーの見た目を固定した(`WalkingCharacter`)。顔素材が無いIDは従来の全身SVGへフォールバック。外側の `.sprite` ラッパーが既存の状態別モーション(歩行/待機/作業/会議など)をそのまま受ける。
- **吹き出し**: 各キャラの上に会話・状態の吹き出しを表示する。内容は次のどちらかに限り、架空の進捗・数値は作らない。
  - **状態(真実)**: `display.state` から導く文言(制作中/品質チェック中/打ち合わせ中/承認おねがいします〈実件数〉/一時停止中/エラー確認中)。
  - **小話(中立)**: idle/done の社員がラウンジで交わす、業務を主張しない雑談(おつかれさま/少し休憩/いい天気 など)。
- `prefers-reduced-motion: reduce` では吹き出しも歩行も出さない。吹き出しは `aria-hidden`、操作は社員ボタンの `aria-label` を維持。

## V4.6.1: 焼き込み画像の廃止(矛盾・架空データの解消)

`office-reference.png`(背景の全景画像)には、デザイン参照時の**仮キャラ名(アオイ/ミナト/リク/ユウキ/サクラ/ハル/カケル/モモカ)・作り物の状態バッジ・存在しない経過時間「01:24:37」・実在しないモデル「Sonnet」・架空の成果物カード**が画素として焼き込まれていた。これは実在9名(葵/蓮/凛/昊/琴葉/紬/紫苑/湊/陽葵)と矛盾し、かつ「架空の経過時間・進捗・状態を出さない」不変条件に反する。

→ **背景画像の使用を廃止**し、オフィスの床・部屋・会議テーブル・ラウンジ・自席(机)・準備中4部門を**コード(CSS/DOM)で生成**する方式へ変更(`office-floor` / `office-room` / `office-zone` / `office-desk` / `office-depts`)。

- 表示される人物は**実在9名のみ**(顔つき歩行キャラ)。名前・役割・状態・件数・モデルはすべて`CompanyStateView`の実値。
- 準備中の4部門は実際の部門名+「準備中」を表示(実`departments`データ)。
- 経過時間・進捗率・偽モデルは一切表示しない。
- `office-reference.png` は不使用(参照デザインの記録としてファイルは残置。表示・配信はしない)。faces クロップは歩行キャラの頭として引き続き使用。
