### E2E実測(2026-08-10・1回・全工程成功)

`copy-design` → `read-design`(transaction) → `edit-design`(replace_text×3 + delete_element + format_text) → `commit` → `export-design`(png 1080x1350) → curl保存 → 目視照合。成果物: `runs/2026-08-10/canva-test/edited-cover.png`(実測1080x1350)。

**確認できた事実**:
- **文字は一字一句そのまま入る**。「AIはまだ早い」は本当? / 小規模企業の生成AI活用実態 / Bloom-L の3箇所すべて逐語一致。**捏造・改変・脱落・別言語化はゼロ**
- 鉤括弧「」・疑問符? などの記号も正しく保持された
- `delete_element` で、generate-designが指示に反して勝手に入れた画像要素を**確実に除去できた**
- 単語途中改行(「早/い」)が初回発生したが、`format_text`でfont_size 133.9→96・line_height 1.35に変更して**自然な改行位置に修正できた**(決定的操作で制御可能)
- 編集は**トランザクション制**で、commitするまで確定しない。`cancel`で全破棄も可能(事故時の巻き戻しが構造的に可能)

**帰結(2026-08-10時点の事実)**: `generate-design`(AIに絵を描かせる)の事故は§2のとおり不可避だが、**`edit-design`の`replace_text`はAI生成ではなく決定的な文字差し替えであり、§2の事故モードが構造的に起こり得ない**。Satoriが事故ゼロなのと同じ理屈が、Canvaの意匠の上で成立する。

**推奨アーキテクチャ(ブランドテンプレート機能・Teamsプラン不要)**:
1. 代表者がCanvaで**マスターデザインを手作り**(1080x1350。文字はダミー。ここが意匠の源泉=人間の仕事)
2. 投稿ごとに `copy-design` で複製(マスターは不変)
3. `read-design` で文字要素のlocator_idを取得 → `edit-design` の `replace_text` で承認済みコピーを流し込む
4. あふれ・改行崩れは `format_text` で決定的に調整
5. `commit` → `export-design` → 既存の `hybrid-register` / `canva-register` に登録 → 紫苑の視覚QA → 代表者承認(**公開ガードは一切迂回しない**)

## 2. generate-design の信頼性(実測ログ)

2026-07-22〜27、計約15回の生成で観測した事故(いずれも1回以上再現):
- 指定文言の**改変**(「何も出ないと不安になる」→「何も出ない」)
- 指定外テキストの**捏造**: 英語プレースホルダー、存在しないイベント日時、`bloom-l.com`(未確認URL)、**「特別オファー!全商品20%オフ」の偽割引通知**(「文字なし」指定時)
- タイトル途中切れ・単語途中改行・フォント化け(豆腐)
- プロンプト中の `\n` を**文字として描画**
- **禁止指示の無視**: 「空の枠を作らない」→切手風の空枠、「写真禁止」→写真使用、「★等の装飾禁止」→★★★★★
- 本文(長文)の**丸ごと省略**(見出しだけ描く)
- ページ間のデザイン不統一(brand_kitで色は揃うが、レイアウト/背景は毎回別物)

**成功パターン(事実)**: 短文1〜3行だけの単票(フィード表紙)は、brand_kit適用+逐語照合+リトライで合格品が得られることがある(07-27に合格1枚を実運用登録)。**成功率の正確な数値は未計測**(体感1/3前後という以上の主張はしない)。

**追加実測(07-29・料金表)**: 金額入りの料金表ストーリーを生成させたところ、**見出しが存在しない漢字列に化け、金額が455,000円/503,0100円/1.4.70000等に改変**された。**数字・金額を含むクリエイティブのCanva生成は禁止**(営業事故リスク)。料金表は`story-render`のpricingレイアウト(通常コード・逐語描画)で作る。

## 4. Claude(エージェント)の役割分担(実稼働ベース)

- 葵: オーケストレーション・CLI実行(唯一のBash権限)
- 昊→琴葉: 企画→コピー(スキーマ検証つき)
- 椿: Canva生成・候補の逐語照合・書き出し(Canvaツール保有)
- 紫苑: 内容QA+視覚QA(fail closed。承認キュー投入の門番)
- 凛/梓: Web調査(一次情報・複数ソース照合。未確認事項の明示が義務)
- 湊/蓮: 実績値の事実化→改善仮説(V6ループ)
