回答は `DECISIONS.md` に記録済み。以下、各問の回答要旨。

### Q1. Meta連携の現状(公開処理・権限)
InstagramアカウントについてA〜Cを教えてください。
A. アカウント種別(個人 / プロ=ビジネス / プロ=クリエイター)
B. Facebookページとの連携有無
C. 第2段階でMeta Graph APIによる予約投稿を目指すことに同意するか
**✅ 回答(2026-07-13)**: 種別・連携状況は現在不明。**MVPは自動投稿を実装せず、承認済み投稿の書き出し+手動投稿まで**。第2段階でアカウント設定を確認し、条件を満たす場合にGraph API予約投稿を検討。

### Q2. 予算枠の使途(費用)
MVPは追加費用0円/月(Maxプラン枠+OSSのみ)で設計しました。将来、Anthropic API・有料フォント・画像素材等で月5,000円枠を使う場合、**「事前に費用見積もりを提示し、代表者が承認するまで有効化しない」**運用でよいですか。
**✅ 回答(2026-07-13)**: デフォルト承認。Max以外の有料API・素材・サービスは事前に月額・従量費用と必要性を提示し、**代表者承認まで有効化しない。MVP追加費用は原則0円**。

### Q3. 通知メールの認証方式(セキュリティ・権限)
第2段階の通知メールにGoogle WorkspaceのGmailを使う場合、(a) Gmail API + OAuth(推奨・トークンはローカル保管) (b) SMTP + アプリパスワード (c) メール通知は不要、のどれにしますか。
**✅ 回答(2026-07-13)**: MVPはダッシュボード内通知のみ。メールは第2段階で検討し、実装時は**(a) Gmail API + OAuthを第一候補**。**SMTP+アプリパスワードは原則使用しない**。

### Q4. 実績3件の顧客名・URL公開(公開処理・権利)
仕様§7では「3件とも公開可能」ですが同意は口頭です。投稿で顧客名・URL・画面を出す前に、(a) DMまたはメールで公開範囲を明記した同意を取得し記録する (b) 当面は顧客名を伏せ「泉州の◯◯業者様」等の匿名表記にする、のどちらにしますか。
**✅ 回答(2026-07-13)**: (a)を採用。3件とも公開できる認識だが、顧客名・URL・画面・推薦コメントの投稿使用前に**メールまたはDMで公開範囲を確認し同意記録を保存**。記録取得までは「権利確認待ち」とし、無断で投稿へ使用しない。

### Q5. DM本文の保存(セキュリティ・プライバシー)
DM支援ワークフローでは代表者がDM本文を貼り付けて取り込みます。個人情報を含むため、(a) 原文をローカルDBに保存(保持期間: 提案180日) (b) AI処理後は要約のみ保存し原文は破棄、のどちらにしますか。
**✅ 回答(2026-07-13)**: (b)を承認。原文は個人情報マスキング→AI処理後に破棄。ローカルDBには**要約・分類・対応状況のみ**保存。※DM支援機能自体はMVPスコープ外(第2段階)となった(→ `17`)。
