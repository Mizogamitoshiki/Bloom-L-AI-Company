# 28. Instagramストーリー運用・デザインガイド(V8, 2026-07-27)

市場調査(凛: 運用・コンテンツ / 梓: 視覚デザイン検証・複数ソース照合)に基づく、Bloom-Lのストーリー運用の正。
調査の出典・詳細は本ドキュメント末尾の出典リストと、DECISIONS.md D-18 追記を参照。

## 1. 結論(アーキテクチャ)

- **ストーリーの描画は通常コード(`company story-render`)が行う。** Canva生成AIは文言改変・捏造(偽の割引通知等)・禁止指示の無視が再現性高く発生し、妥協のない品質に達しない(2026-07-27 実測で確定)
- **Canvaの役割**: 代表者がCanvaアプリ(Proのストーリーテンプレート)で自作した意欲作を、椿が取り込む経路(search-designs → export-design → 08_stories)。手動高品質枠として併存
- ストーリーは24hで消える簡易メディアのため**フィードの承認パイプラインには載せない**。/stories ページからダウンロード → Instagramアプリで手動投稿

## 2. デザイン仕様(梓の複数ソース照合。story.tsが強制)

- キャンバス 1080×1920 / セーフゾーン: **上270px・下380px・左右65px**(Meta広告比率14%/20%/6%準拠の厳しめ。公式一次未確認のため実機で最終確認)
- Reels兼用素材は下部670pxを空ける
- 見出し特大(実装76px)・1枚の合計文字量 **60字以内**(schemaが拒否)・和文ゴシック
- 濃紺基調・白余白多め・**ゴールドは差し色のみ(細線・小ラベル。面積5〜10%)**
- 写真に文字直載せ禁止。コントラスト4.5:1以上
- リンクスティッカーは中央〜中1/3へ(最下部禁止)。CTA文字も下部380pxに置かない

## 3. 刺さるコンテンツの型(凛の調査。効果数値はBloom-L実測で要検証)

| 型 | やり方 | 狙うKPI |
|---|---|---|
| 質問スタンプ | 「HPのこと、何に困ってますか?」→後日回答ストーリー | 返信・DM流入 |
| 二択投票 | 泉州の事業者あるあるを二択で | スタンプ反応率 |
| 新着投稿の告知 | フィード投稿公開後に`announce`レイアウトで再シェア | プロフィール遷移 |
| ビフォーアフター | 旧サイト→リニューアル後(**顧客許可記録必須**) | 保存・遷移 |
| 舞台裏 | 制作工程・ヒアリング風景(顧客情報の映り込み禁止) | 親近感・閲覧維持 |

- DM誘導: 返信ボタン活用(Mosseri推奨)+「気になる方はDMで『相談』」を全媒体で一貫
- 時間帯の候補: 朝6-9 / 昼12-13 / 夜19-22(アカウントのインサイトで要検証)
- 頻度: 出典間でばらつき(日3-5回説・週5-7回説)。まず**フィード投稿告知+週2-3本**から始めて実測で調整

## 4. 作り方(オーケストレーター/椿)

```bash
pnpm company story-render --json '{"kind":"story_spec","hook":"HPのこと、\n何に困ってますか?","sub":"質問スタンプで教えてください","layout":"hook-center"}' --output ask
```
- `layout`: `hook-center`(問いかけ/宣言) / `announce`(NEW POSTラベル付き告知)
- `cta`は白ピルバッジ(セーフゾーン内)。リンク/質問/投票スタンプはInstagramアプリで重ねる
- 出力は `data/workspace/08_stories/` → ダッシュボード /stories に自動表示

## 5. Canva MCPの限界(2026-07-24〜27の実測。再調査時の前提)

- `generate-design`: 文言逐語・禁止事項(空枠・URL・写真・装飾)・レイアウト指示・「文字なし」のいずれも**確実には守らない**。偽の割引通知の捏造も発生
- プロンプト中の`\n`は文字として描画される
- 編集トランザクション・autofill・`get-design-content`はコネクタ未提供 / ブランドテンプレート公開はTeams必須
- 有効なのは: ブランドキット(色統一)・書き出し(export-design)・候補の目視照合。**短文1枚(フィード表紙)なら実用**、それ以上は不可
