# 03. 事業・SNS戦略

## 1. ポジショニング【確定に基づく整理】

- 誰に: 泉州地域でまだHPを持たない会社・個人事業主
- 何を: 「投資対効果の高いITサービス」— 格安ではなく、速い・柔軟・地域密着・最新技術
- どう伝えるか: 専門用語を顧客利益に翻訳(Next.js → 「表示が速い」「更新しやすい」「検索に強い」「安心して長く使える」)
- どこへ: Instagram DM相談(HP完成後はHP・実績・フォーム・予約へ)

## 2. 梅プラン採算検証【推奨 — 分析結果。価格変更はしない(§4)】

### 工数見積もり(AI支援を最大活用した場合)

| 工程 | 従来手作業 | AI支援+テンプレート運用 |
|---|---|---|
| ヒアリング・要件整理 | 3h | 2h |
| 構成・ワイヤー(7p) | 4h | 1.5h(型化) |
| 文章作成(7p分) | 6h | 2h(AI下書き+人手修正) |
| デザイン・実装(7p) | 14h | 7h(テンプレート+差し替え) |
| フォーム・サーバー・ドメイン | 3h | 1.5h(手順書化) |
| 修正対応(納品前) | 4h | 2h(修正2回上限を明示) |
| **合計** | **34h** | **16h** |

### 採算判定

- 従来手作業: 45,000円 ÷ 34h ≒ **時給1,324円 → 採算不成立**
- AI支援+テンプレート: 45,000円 ÷ 16h ≒ **時給2,813円 → 単体では薄利だが成立**
- 保守のLTV込み: 月7,000円 × 12か月 = 84,000円/年。月3回の軽微修正を平均30分/回(月1.5h)に収めれば保守時給≒4,600円。**梅は「保守とアップセルで回収する獲得商品」と位置付けるのが妥当**

### 成立条件(改善案 — 価格は変えない)

1. **提供範囲の明文化**: 文章作成は「AI下書き+修正1回まで」/ 構成テンプレートは3種から選択 / 納品前修正は2回まで、を契約書・案内に明記
2. **素材期限ルール**: 写真・原稿素材の提出期限を設け、遅延時は納期が自動スライドすることを明記(工数膨張の最大要因を遮断)
3. **7ページの内訳固定**: TOP/サービス/料金/実績/会社概要/お問い合わせ/ブログorお知らせ の標準構成を基本とし、逸脱は竹・松へ誘導
4. **軽微修正の定義**: テキスト・画像差し替え、リンク修正まで。レイアウト変更は「大幅な修正」として別途見積もり
5. アップセル動線: 梅契約者に竹(CMS)・松(リニューアル)を提案する導線をSNS・保守レポートに組み込む

## 3. 竹プラン推奨案【2026-07-13 社内検証用の仮価格として承認。代表者の再承認までSNS・営業資料で確定価格として公開しない】

| 項目 | 推奨 | 根拠 |
|---|---|---|
| 制作費 | **120,000円** | 梅45,000と松500,000の対数的中間。CMS初期設定+コンテンツモデル設計の追加工数(約8〜10h)を吸収 |
| 保守費 | **月12,000円** | 梅7,000+CMSホスティング/サポート原価+利益。CMS利用料を内包し「顧客は追加費用なしで自分で更新できる」と訴求 |
| ページ数 | 最大10ページ | 梅(7)との差別化。CMS前提でお知らせ・ブログは無制限に増やせる点が本質的価値 |
| CMS提供 | Bloom-L独自CMSのテナント1件(お知らせ+ブログの2モデル標準) | 独自CMSという強み(§5)の商品化 |
| 修正 | 月3回軽微修正(梅同等)+ CMS操作サポート(月1回まで) | 「自分で更新できる」が主価値のため修正枠は増やさない |
| 差別化の一言 | 梅=「持つ」、竹=「自分で育てる」、松=「攻めの集客資産」 | SNS発信でもこの対比で語る |

## 4. 松プラン「修正無制限」のフェアユース設計【推奨(§4の設計指示)】

表現は **「既存ページの修正 回数無制限(公正利用の範囲)」** とし、以下を契約書に明記する。

| 項目 | 条件 |
|---|---|
| 対象作業 | 既存ページのテキスト・画像差し替え、既存セクション内の軽微なスタイル調整、リンク・営業時間等の情報更新、既存機能の設定変更 |
| 対象外(別途見積もり) | 新規ページ追加、情報設計・ナビゲーション変更、新機能開発、デザインリニューアル、掲載原稿の新規執筆、予約・決済・会員機能 |
| 対応時間 | 営業日ベースで受付から48時間以内に着手、軽微なものは5営業日以内に完了目安 |
| 同時依頼数 | 同時進行3件まで(4件目以降はキュー待ち) |
| フェアユース上限 | 月あたり合計10時間相当を目安。超過が2か月続く場合は運用内容の見直しを協議(自動追加課金はしない) |
| 緊急対応 | サイト停止・表示崩れ等の障害は上記と別枠で最優先対応 |

## 5. SNS戦略

### 5.1 ファネル設計【確定+推奨】

```
発見(リール・カルーセル・ハッシュタグ・地域タグ)
  → 興味(保存されるノウハウ・実績のビフォーアフター)
  → 信頼(プロフィール: 実績3件・地域・強み・人柄)
  → 行動(CTA: 「DMで無料相談」/ HP完成後はプロフィールリンク)
```

- CTAはサービス優先順位(§3)を反映: 基本CTA=HP制作の無料相談。LP・自動化は文脈に応じ、SaaS・業務システムは投稿では紹介に留め売り込まない【確定】

### 5.2 コンテンツの柱と配分【推奨】(柱は§6で確定)

| 柱 | 配分 | 主形式 | 狙い |
|---|---|---|---|
| ⑥泉州のHP未保有事業者の課題解決 | 30% | カルーセル・チェックリスト | 保存・共感・地域到達 |
| ③HP導入で事業がどう変わる | 20% | 前後比較・図解 | 需要喚起 |
| ⑤実績・技術紹介 | 20% | スクロール動画・モックアップ | 信頼・具体性(1実績→複数投稿展開) |
| ②現代のHPの役割 / ④気になるWeb・ITトピック | 20% | 字幕解説・FAQ | 発見・教育 |
| ①IT・AIニュース | 10% | カルーセル | 発見・先進性(情報品質ルール§15厳守) |

### 5.3 投稿ペースとカレンダー【推奨】

- 初期4週: **週3本**(例: 月=課題解決、水=実績or図解、金=ニュースorFAQ)+ストーリーズは任意
- 30日ごとにKPIレビューで増減(→ `15`)。継続率>本数
- ハッシュタグ: 地域(#泉州 #岸和田 #貝塚 #泉佐野 等) + 業種 + 課題系を各投稿5〜15個、AIが候補提示し品質管理が重複・禁止語を検査

### 5.4 禁止・注意表現(§15確定の運用ルール)

- 効果保証(「必ず売上が増える」等)・誇大表現の禁止 / SEO・AEO効果を保証しない
- 他者画像の無断転載禁止 / 引用は出典明記かつ必要最小限
- 顧客名・画面は許可記録(→ `13`)がある場合のみ / 許可前の顧客発言の脚色・断定禁止
- 単一情報源のニュース断定禁止 / 公開日・確認日のない情報は投稿不可
